【言葉のくせのチェック】
 「頑張ります」だけで終わる、「貴社」と言う（話し言葉は「御社」）、くだけた言い方（「〜みたいな」「〜っていう」）を使うと、アドバイスに言い換えの例が表示されます（目安点の「話し方」も少し下がります）。
 ホームの「言葉のくせを直す（言い換え集）」にも、言い換えの例を載せています。
 ※この生徒に特有のくせが分かったら、index.html の HABITS（言葉のくせ）の部分を書き換えると、チェックが増やせます。

【2. 事前に必ず確認すること（ページの「直前までに確認すること」「避けたい回答（NG集）」にも載っています）】

 ・模範例にある会社の数字（シェア、売上、年号、新商品、研究発表など）は、2026年11月1日時点で調べた内容です。面接の直前に、公式サイト（kaneryo.co.jp）の「お知らせ」で、最新の情報を確認してください。

 ・売上は、グループ計で243億円（2024年4月時点、公式サイト）、255億円（2025年4月時点、マイナビ）と、資料により異なります。出典と時点をそえて話します。

 ・公務員試験を受けていない場合は、「公務員ではなく民間企業を選んだ理由」の問題を、「なぜ民間企業のカネリョウか」を答える練習として使います。

【3. 読み上げ音声を作る（VOICEVOX・任意）】
 VOICEVOXを起動したまま、このフォルダで  python make_audio.py
 audio フォルダができるので、index.html と同じ場所に置きます。
 音声がない間は、ブラウザ内蔵の声で読み上げます。ホームの「ブラウザの声」で声を選べます（Chromeの「Google 日本語」がおすすめ）。
 読み上げの声が使えない端末では、「隠す」設定でも質問の文字を表示します。
 「カネリョウ海藻」「宇土」「御社」「SQF」「HACCP」などの読み方は、questions.js の reading に登録ずみです。読み間違いがあれば、そこに追加して --force で作り直します。
 VOICEVOXと各キャラクターの利用規約・クレジット表記（ページ下に自動表示）をご確認ください。
